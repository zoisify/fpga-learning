# 01 - Basic sequential logic

**Status:** planned.

## What it will demonstrate

- counters and clocked state;
- reset behaviour;
- deriving a slow enable/toggle from a faster simulation clock;
- simulation-first development with a self-checking testbench;
- first Vivado synthesis flow once the simulator version is stable.

## Scope

Two small modules: a parameterised counter and an LED blinker. Hardware mapping comes later; the first acceptance criterion is simulation.

## Verification target

Check reset, count progression, wraparound, and expected LED toggle interval automatically.
