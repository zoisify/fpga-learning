# 02 - Traffic-light FSM

**Status:** planned.

## What it will demonstrate

- finite-state-machine structure;
- explicit state transitions and timed dwell periods;
- state-sequence verification with a self-checking testbench.

## Scope

Implement a timed traffic-light sequence in Verilog. VHDL effort is reserved for the UART and SPI projects.

## Verification target

Walk every legal transition, test reset from multiple states, and fail automatically on an invalid output combination or incorrect dwell time.
