# Traffic light FSM

**Status:** not started yet - this is a placeholder while I work through the
earlier projects.

A timed finite state machine driving a UK traffic-light sequence, with a testbench
that walks every state transition.

This project also gets a **VHDL port**: the same FSM written in VHDL alongside the
Verilog original. Most UK FPGA teams are VHDL-first, so the portfolio needs to show
working VHDL, not just Verilog/SystemVerilog.

When this project lands it will include the RTL, a self-checking testbench (see
[TESTING.md](../TESTING.md)), and design notes with a "what I tried differently"
section.
