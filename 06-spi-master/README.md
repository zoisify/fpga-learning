# 06 - SPI master in VHDL

**Status:** planned.

## What it will demonstrate

- VHDL RTL used as the primary implementation language;
- SPI mode-0 transaction control;
- clock-divider and shift-register logic;
- verification against a simulated slave endpoint.

## Scope

Implement a single-master, single-slave SPI controller in VHDL. Begin with mode 0 and a configurable clock divider; additional modes are optional.

## Verification target

Check chip-select timing, clock edges, MOSI ordering, MISO capture, multiple words, reset, and back-to-back transfers.
